# v1 owner hand-offs ([#1020](https://github.com/srikanth235/centraid/issues/1020))

Everything the v1 platform needs that a container with no phone, no Xcode, no Android SDK and no rented host could not do. This is the **canonical** list: the umbrella receipt records each one where it was found, and this file is where they are read together.

Every row names the **exact command**, the **evidence to hand back**, and **where the result goes** — a ledger key, a decision row, or a parked ceiling that gets promoted. A hand-off with no destination is a note; one with a destination is work.

Nothing here is a missing feature. Each is a claim this repository deliberately refused to make on hardware that could not support it: a skipped test that reads green, a DACL nobody watched refuse anybody, a ceiling filled from the wrong machine. Where a lane could not prove something it **fails loudly** or **refuses** rather than passing.
