## Decisions

#801 remaps coverage scope keys from retired packages (protocol/blob-format/time-engine/gateway/app-engine/automation/agent-runtime) onto packages/core/src/{protocol,blob,time} and packages/server/src/{engine,automation,acp} plus the former-gateway dir brace; every numeric floor is unchanged. Prior: @vitest/coverage-v8 4 (#565) made AST-aware remapping the only mode, redefining what counts as a branch (optional chaining, nullish coalescing, default params, nested arrows). This is a MEASUREMENT change, not lost coverage — proven by packages/tunnel, packages/backup, packages/agent-runtime and packages/cli, which have ZERO source or test changes vs origin/main yet all moved (tunnel branches 80 -> 52.67). Local and CI agree within 0.06pt, so it is deterministic, not runner variance.
