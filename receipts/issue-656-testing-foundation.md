Inputs, in order: owner exists and declares tests (**a zero-test owner is a `gap` at PR time**, no lane run needed); no inventoried skip site and no default-CI env gate; a flow with a met `minimumTests`; the declared owner owns one of the cell's flows and no backing file is **oversubscribed** (floors owned > tests declared — this is what kills "one 4-test file owns 15 accessibility cells" as a class); a tier-appropriate adversary (coverage-floor scope for unit/contract/integration, registered rig budget for perf/scale); mutation, where a seeded package under `_absoluteWeaknessBelow` can never back `solid`; and finally run evidence, which can only *lower*.
