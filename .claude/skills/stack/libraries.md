# Chosen libraries

**A new dependency is a product call.** Do not add a crate, Swift package, Gradle plugin or npm package for convenience. Every dependency expands the attack surface, slows the edit-run loop, and must pass `cargo deny` (licences and advisories) and `dependency-review` in CI. When a job is already covered by a library below, use it; when nothing covers it, ask the owner before adding one.

## Rust workspace (pinned in `Cargo.toml` / `Cargo.lock`)

| Job | Library | Notes |
| --- | --- | --- |
| Vault storage | `rusqlite` (bundled SQLCipher) | SQL stays in `ontology`, `vault`, `search`, `domain` |
| Hashing & KDF | `blake3`, `argon2` | One hash across the vault (`BLAKE3`); `sha2` lives only in `xtask` for external protocols |
| Wire & FFI contracts | `prost`, `prost-types` | Protobuf over the 5-symbol C ABI; additive only |
| Async & HTTP (gateway) | `tokio`, `axum`, `reqwest`, `quinn` | No listening socket on the phone |
| CLI & tooling | `clap`, `anyhow`, `thiserror`, `serde`, `serde_json`, `toml` | `thiserror` in libraries, `anyhow` at binary/tooling edges |
| Property-based testing | `proptest` | Deterministic shrinking for parsers, codecs, canonicalizers, state invariants |
| Temp fixtures | `tempfile` | Dev-dependency for isolated test trees |

## Mobile shells (pinned in `mobile/gradle/libs.versions.toml` and `mobile/iosApp/project.yml`)

| Platform | Job | Library | Notes |
| --- | --- | --- | --- |
| Android | UI & navigation | Jetpack Compose (BOM pinned in `libs.versions.toml`) | Material 3 tokens generated from `design/tokens.toml` |
| Android | Core FFI | JNA (`net.java.dev.jna`) | Tested by `cargo xtask gate --profile mobile-jvm` |
| Android | Screenshot goldens | Roborazzi (when applied) | Pinned in `libs.versions.toml`; snapshots live under test goldens |
| iOS | UI | SwiftUI + UIKit (XcodeGen `project.yml`) | Design tables generated by `cargo xtask design` |
| iOS | Wire types | `swift-protobuf` | Generated in Xcode pre-build phase |
| Both | End-to-end flows | Maestro (`MAESTRO_VERSION=2.6.1`) | Shared flows under `mobile/maestro/flows/` |

## Static sites (pinned in `package.json` / `bun.lock`)

Only the two static web sites (`scripts/docs-site`, `scripts/home-site`) use JavaScript packages: `astro`, `jsdom`, and `pagefind`. No formatter, linter, test runner or TypeScript toolchain is installed for repository tooling; see [toolchain.md](toolchain.md).
