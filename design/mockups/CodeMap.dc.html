Words the canvas invented

Not in the core's strings yet. Each goes into strings in the PR that builds the screen, or the board changes to the core's word.

  • Reminders home: Completed, My Lists, Add List, Scheduled, Flagged, Invites; band Calendar · Reminders · Invites.
  • Today: Tonight, New Reminder, Every 3 days, 5 to do.
  • Backup: What travels when, Back up over, Wi-Fi only.
  • Locker: Unlocked, Recently used, Codes.
  • Money: Need a category (core: “{n} rows need a category”).

Rules

  • A board that changes a screen names its screen id here.
  • New controls get a selector id on both platforms, listed in selectors.md, in the same PR.
  • Locker item has no selector ids yet; add them before its revamp.
  • Names that differ (Summary vs Today in Health) are settled before building, not during.
