The live vault

The phone keeps one SQLite vault. The Rust core is its only writer; the nine apps use its shared typed records, links, history, and search.

How screens work through the core

Records, links, and bytes

A record has an identity and history. A link describes a chosen relationship. Original file bytes may live in the phone’s content store, remain in the phone’s photo library, or be available from a backup. Previews and extracted text are derivatives; imported and followed records retain their source details.

Backup copies

The phone seals vault data and content files before sending them to a backup device. The device stores sealed objects; it does not query or write the live vault.
