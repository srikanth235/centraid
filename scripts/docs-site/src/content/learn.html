Data · connected records

Separate things.
Useful connections.

A note links to a document. A reminder links to that note. Each remains its own record.

One phone vault

The phone core reads and writes the records. Apps do not keep separate copies.

Backup stays sealed

The phone seals backup data before sending. A gateway cannot read records or answer app queries.

How apps use the shared model

Apps read and act through typed operations in the phone core. A chosen action changes the vault; a link relates records without duplicating their contents.

What a backup device receives

The phone sends sealed backup data to a device you control. The device stores that copy but cannot open it or answer app queries.

Where to find the complete schema

The ontology reference lists record kinds, relations and their constraints.
