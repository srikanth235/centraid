01 · shared records

Apps can link records

A link describes a relationship between records; it does not merge them or automatically create another link. Read the full record reference.

02 · phone storage

The phone is the vault

The Rust core on the phone is the live vault’s only writer. Apps use the same local records and continue working offline. See where records live.

03 · protected values

Locker keeps values sealed

Locker can list item details without revealing protected values. Reveal requires the phone owner’s check. Read about privacy.

04 · sealed copy

Backup travels separately

A backup device stores sealed data from the phone; it does not become another live vault. Set up a backup.

05 · reviewed changes

Actions wait for you

The assistant can find records and prepare typed actions. The phone core checks each change, and writes wait for your confirmation. Use the assistant.
