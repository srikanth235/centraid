# Pixel Jumper

An original single-file HTML5 side-scrolling platformer inspired by classic
8-bit platformers. All art, levels, and code are original — it is **not**
affiliated with, and does not reuse assets from, any existing commercial game.

## Play

Open `index.html` in any modern browser. No build step, no dependencies.

## Controls

| Key | Action |
| --- | --- |
| ← / → | Move |
| Z or Shift (hold) | Run |
| ↑ or Space | Jump (hold for higher jumps) |
| ↓ | Crouch (when big) |
| **S** | Shoot fireball (with the Fire Flower power-up) |
| P | Pause |
| Enter | Start / advance |

## Features

- Run/jump physics with variable jump height, acceleration, and friction
- Power-ups: **Grow Mushroom** (get big), **Fire Flower** (shoot fireballs with S),
  **Star** (temporary invincibility)
- Enemies: walkers you can stomp, and shell creatures you can stomp then kick
- `?` blocks (coins / power-ups), breakable brick blocks, pipes, coins, flagpole goal
- 5 original levels across overworld, underground, sky, castle, and a larger overworld
- Scrolling camera, HUD (score, coins, world, time, lives, power), particles, and beep SFX
- Touch controls on mobile / coarse-pointer devices
