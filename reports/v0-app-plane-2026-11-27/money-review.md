# Money review evidence (M4)

This packet records observable Money behavior for owner review. It does not request or record M4 approval, and it does not mark a progress checkbox.

## Evidence scope

Room captures are protobuf `Room` responses from the real Rust Core runtime after registered vault commands. Android previews are Compose/Robolectric renderings of those Room protobufs, not device screenshots, native UI approval, or evidence that an OS action completed. The Android renderer produced light and dark variants for all current fixtures.

The [durable Room fixture manifest](room-fixtures.json) currently lists 20 fixtures, including 13 Money fixtures. The latest capture used `CENTRAID_REVIEW_CAPTURE=1`; the suite asserts the unanswered date-order question has no preview, the two-row selection state is visible, the second statement import reports `unchanged == 1`, and the statement detail contains both split parts. Compose/Robolectric rendered all 20 fixtures in light and dark mode (40 previews).
