### bracketed-replica-writes

- **Directive**: outside the gateway's invocation pipeline, a raw `INSERT`/`UPDATE`/`DELETE` against a table a seat replicates must run inside the replica commit pair — `withReplicaCommit`, an explicit `beginReplicaCommit`/`endReplicaCommit`, or a connection `bracketReplicaWrites` has wrapped. Judged over `packages/server/src/**` (minus `engine/**`, whose connection is bracketed at the seam by `makeReplicatedLedgerDbProvider`, because engine may not import `@centraid/vault`) and over `packages/vault/src/gateway/gateway.ts` and `duties.ts`, the two duty entry points outside the pipeline. The replicated set is derived from the vault schema's own `CREATE TABLE` statements minus `PRIVATE_TABLES` minus the log plane's tables — the same three subtractions `replicatedTablesOf` makes.
- **Rationale**: session capture is the only mechanism that puts a gateway write on a phone, and the sessions are open only between `beginReplicaCommit` and `endReplicaCommit`. A write outside the pair reaches the trigger log and the SSE feed and therefore looks alive on every surface a developer checks — and never reaches a seat's file until a full re-bootstrap. That is a SILENT loss, not an error, which is why it survived in four separate writers at once (#1014, findings N1, G4, G5, G22, G24): the notices store, the standing sweep, post-rollback bookkeeping, and every connection a worker subprocess opened by path. Nothing in the type system, the tests or the lint catalog said a word about any of them. A convention a writer has to remember is not a contract; a check that reads the diff is.
- **Enforced by**: `.governance/packs/srikanth235/centraid/directives/bracketed-replica-writes/check.sh`
- **Door**: hook (pre-commit), and again in CI.
- **Host enforces**: the `governance` workflow.
- **Rule observes**: whether the pair is around the RIGHT statements — it reads the file, not the call graph, so a file that brackets one write and not its neighbour passes. What it makes impossible is a writer with no pair anywhere in it, which is the shape every #1014 loss had.
- **Exceptions**: per-line waiver `// governance: allow-bracketed-replica-writes <reason>` for a write that genuinely must not be captured.
